# Dataset

The project uses the DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS dataset.

For local execution, place:

`DataCoSupplyChainDataset.csv`

inside `data/raw/`.

The ZIP supplied for this internship project contains the actual CSV for
reproducible local execution. Before pushing to a public GitHub repository,
check the dataset's license/redistribution terms and remove the raw CSV if
redistribution is not permitted.
