# Week 3 Methodology

1. Load the actual DataCo dataset.
2. Convert order-date values to datetime.
3. Create delivery-delay and late-risk analytical fields.
4. Calculate descriptive statistics.
5. Calculate selected numeric correlations.
6. Compare late-delivery rates by shipping mode and market.
7. Analyze actual shipping-day distribution.
8. Analyze top product categories by sales.
9. Save charts as PNG files.
10. Write a concise data-backed insight file.
